# Clinical knowledge data

This directory contains structured development-time reference records, a source registry, a guideline catalogue, and medication-safety rules used by the application.

These materials are not a clinically approved protocol or prescribing guide. A licensed clinician must review them and align them with current local guidance, product labels, medication availability, and applicable law before clinical use. The system must not prescribe autonomously.

The source registry and guideline catalogue identify the references used to prepare these records. External references retain their original terms and ownership. No performance or clinical-outcome claim is made by including this data.
